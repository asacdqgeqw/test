افزونه المنتور با ۹ ویجت تعاملی و حرفه‌ای برای ساخت لندینگ‌پیج فارسی RTL.

== Description ==

افزونه Vira Sections شامل ۹ ویجت تعاملی برای المنتور است:

1. **Hero (Vira)** — بنر اصلی با Aurora گرادیان، Tilt 3D، کلمات چرخان و شمارنده انیمیشنی
2. **Services Bento (Vira)** — گرید Bento انعطاف‌پذیر برای معرفی خدمات
3. **Interactive Tabs (Vira)** — تب‌های تعاملی با پنل گرادیانی و KPI‌ها
4. **Process Timeline (Vira)** — تایم‌لاین کلیک‌شونده با پنل جزئیات
5. **Tech Stack (Vira)** — نمایش تکنولوژی با تب، کد و گرید لوگوها
6. **Pricing (Vira)** — کارت‌های قیمت با Toggle ماهانه/سالانه
7. **Testimonials Slider (Vira)** — اسلایدر ۳بعدی نظرات با metric badge
8. **FAQ Search (Vira)** — سوالات متداول با جستجو و فیلتر دسته‌بندی
9. **CTA Form (Vira)** — فرم دعوت به اقدام با glass-morphism

= ویژگی‌ها =

* تمام متن‌ها قابل ویرایش از پنل المنتور
* رنگ‌ها، گرادیان‌ها و اندازه‌ها قابل تنظیم
* پشتیبانی از تصاویر سفارشی (در Hero و Testimonials)
* RTL کامل
* ریسپانسیو
* فونت Vazirmatn با امکان غیرفعال‌سازی
* ایزوله بودن استایل‌ها (با ID اختصاصی هر ویجت — تداخل ندارند)

= نیازمندی‌ها =

* WordPress 6.0+
* Elementor 3.0+ (Free یا Pro هر دو)
* PHP 7.4+

== Installation ==

1. فایل zip افزونه را در `Plugins → Add New → Upload` آپلود کن.
2. افزونه را فعال کن.
3. وارد المنتور شو و در پنل ویجت‌ها دنبال "Vira Sections" بگرد.

== Frequently Asked Questions ==

= آیا با المنتور Free کار می‌کند؟ =

بله. تمام ۹ ویجت با المنتور Free و Pro کار می‌کنند.

= چطور رنگ‌ها را تغییر دهم؟ =

روی هر ویجت در ویرایشگر المنتور کلیک کن، به تب Style برو و رنگ‌های دلخواه را انتخاب کن.

= آیا می‌توانم تصویر آپلود کنم؟ =

در ویجت Hero می‌توانی به جای Mockup تصویر سفارشی آپلود کنی. در Testimonials نیز می‌توانی برای هر فرد تصویر آواتار آپلود کنی. در Tech Stack نیز برای لوگوها تصویر قابل آپلود است.
