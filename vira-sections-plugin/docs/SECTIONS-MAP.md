## ✉️ ویجت CTA Form با ارسال ایمیل واقعی

ویجت **CTA Form (Vira)** حالا کامل کار می‌کنه:

### امکانات:
- ✅ ذخیره پیام در دیتابیس (Custom Post Type `vira_lead`)
- ✅ نمایش لیست پیام‌ها در پنل وردپرس → **Vira Sections → پیام‌های فرم**
- ✅ ارسال ایمیل HTML قشنگ با لینک «مشاهده در پنل»
- ✅ Reply-To خودکار به ایمیل فرستنده
- ✅ Honeypot ضد اسپم (مخفی)
- ✅ AJAX با nonce (امن)
- ✅ Validation سرور-side
- ✅ ذخیره IP، User Agent، صفحه ارسال
- ✅ پشتیبانی از چند ایمیل دریافت‌کننده (با کاما جدا کنید)

### تنظیمات:
**پیشخوان وردپرس → Vira Sections**

| تنظیم | پیش‌فرض |
|---|---|
| فعال‌سازی ارسال ایمیل | ✅ |
| ایمیل دریافت‌کننده | ایمیل ادمین سایت |
| عنوان ایمیل | درخواست جدید از سایت |

### مشاهده پیام‌ها:
**پیشخوان وردپرس → Vira Sections → پیام‌های فرم**

ستون‌های لیست: نام فرستنده، تلفن، ایمیل، موضوع، خلاصه پیام، تاریخ.

با کلیک روی هر پیام، تمام جزئیات (شامل IP، User Agent، صفحه ارسال) قابل مشاهده است.

### عمل‌های آینده (هوک):
```php
// Hook for CRM/SMS integration:
add_action( 'vira_sections_lead_saved', function( $post_id, $data ) {
    // $data: name, phone, email, select, message, page_url
    // Send to your CRM or SMS gateway here.
}, 10, 2 );
```
