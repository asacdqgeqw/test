# 📦 راهنمای نصب و استفاده افزونه Vira Sections

## ✅ پیش‌نیازها

- WordPress 6.0 یا بالاتر
- Elementor 3.0+ (نسخه رایگان یا Pro هر دو پشتیبانی می‌شوند)
- PHP 7.4 یا بالاتر

---

## 🚀 نصب در ۳ روش

### روش ۱: نصب از فایل ZIP (توصیه می‌شود)

1. کل پوشه `vira-sections-plugin` را به فایل **ZIP** تبدیل کن
2. در وردپرس برو به: **افزونه‌ها → افزودن → بارگذاری افزونه**
3. فایل ZIP را آپلود کن و **نصب** را بزن
4. **فعال‌سازی** را کلیک کن

### روش ۲: آپلود از طریق FTP

1. کل پوشه `vira-sections-plugin` را در `wp-content/plugins/` آپلود کن
2. در پنل وردپرس → **افزونه‌ها** برو
3. افزونه **Vira Sections** را پیدا کن و **فعال** کن

### روش ۳: گیت

```bash
cd wp-content/plugins
git clone https://github.com/asacdqgeqw/test.git vira-sections-temp
cp -r vira-sections-temp/vira-sections-plugin ./vira-sections
rm -rf vira-sections-temp
```

سپس از پنل وردپرس فعال کن.

## 🎨 استفاده در المنتور

### پیدا کردن ویجت‌ها

1. روی هر صفحه‌ای **«ویرایش با المنتور»** را بزن
2. در پنل سمت راست (یا چپ بسته به زبان)، در باکس جستجو تایپ کن: **`vira`** یا **`Vira`**
3. ۹ ویجت زیر را خواهی دید:

| ویجت | آیکن | کاربرد |
|---|---|---|
| Hero (Vira) | 🎨 banner | بنر اصلی صفحه |
| Services Bento (Vira) | 📦 grid | معرفی خدمات/محصولات |
| Interactive Tabs (Vira) | 📑 tabs | تب‌های تعاملی |
| Process Timeline (Vira) | ⏱️ timeline | فرآیند کار / مراحل |
| Tech Stack (Vira) | 💻 code | تکنولوژی‌ها |
| Pricing (Vira) | 💰 price | پکیج‌های قیمت |
| Testimonials Slider (Vira) | 💬 carousel | نظرات مشتریان |
| FAQ Search (Vira) | ❓ help | سوالات متداول |
| CTA Form (Vira) | 📝 form | فرم دعوت به اقدام |

### کشیدن ویجت روی صفحه

1. ویجت دلخواه را روی صفحه **درگ کن**
2. در پنل سمت چپ تب‌های **Content** و **Style** را خواهی دید
3. متن‌ها، رنگ‌ها و تصاویر را به دلخواه تغییر بده
4. **Update** بزن

## ✏️ راهنمای ویرایش هر ویجت

### Hero (Vira)
- **Hero Content**: تیتر، توضیحات، دکمه‌ها
- **Rotating Words**: کلمات چرخان (می‌توانی هر تعداد اضافه کنی)
- **Stats**: آمار با شمارنده انیمیشنی
- **Hero Visual**: انتخاب بین Mockup داخلی، تصویر سفارشی یا بدون تصویر
- **Style → Background**: تغییر رنگ Aurora و پس‌زمینه
- **Style → Colors**: گرادیان دکمه‌ها و کلمات چرخان

### Services Bento (Vira)
- **Service Cards**: کارت‌ها (می‌توانی هر تعداد اضافه/حذف کنی)
- هر کارت: آیکن، عنوان، توضیح، قیمت، لینک، اندازه (small/medium/large)، تیره (دارک کارت)
- **Style → Cards**: رنگ پس‌زمینه، حاشیه

### Interactive Tabs (Vira)
- **Tabs**: هر تب با آیکن، تیتر، KPIها و ویژگی‌ها
- **Settings**: اتو روتیشن + بازه زمانی

### Process Timeline (Vira)
- **Steps**: هر مرحله با شماره، عنوان، مدت، توضیح کامل
- **Settings**: تم تیره/روشن، اتو پلی

### Pricing (Vira)
- **Plans**: کارت‌های قیمت (می‌توانی Featured فعال کنی)
- **Toggle**: امکان فعال/غیرفعال کردن Toggle ماهانه/سالانه
- هر پلن: قیمت ماهانه و سالانه جداگانه

### Testimonials Slider (Vira)
- هر نظر: آواتار (تصویر یا حرف)، نقل قول، نام، شرکت، badge
- **Settings**: اتو پلی + بازه

### FAQ Search (Vira)
- **Categories**: دسته‌بندی‌ها (slug + label)
- **FAQ Items**: سوالات با امکان تخصیص به چند دسته (slug با فاصله)

### Tech Stack (Vira)
- **Tabs**: هر تکنولوژی با کد نمونه
- **Logos**: لوگوها (تصویر یا حرف fallback)

### CTA Form (Vira)
- **Left Content**: متن سمت راست (در RTL)
- **Form**: فیلدها قابل فعال/غیرفعال
- **Form Action URL**: اگر خالی باشد فقط پیام موفقیت نمایش می‌دهد

## ⚙️ تنظیمات سراسری

پنل وردپرس → **Vira Sections** (در منوی اصلی)

- **بارگذاری فونت Vazirmatn**: اگر قالب شما فونت فارسی استاندارد ندارد، این را فعال کن

## 🎨 تغییر رنگ کل سایت

از آنجایی که هر ویجت متغیرهای رنگ خودش را دارد، می‌تونی **رنگ بومی هر صفحه** رو متفاوت کنی. مثلاً:

| صفحه | رنگ تأکیدی |
|---|---|
| طراحی سایت | بنفش `#170C79` |
| سئو | سبز `#22c55e` |
| آموزش | کهربایی `#F59E0B` |
| اپلیکیشن | سبز اندروید `#3DDC84` + بنفش `#A855F7` |

برای تغییر، فقط در **Style → Colors** رنگ دلخواه را انتخاب کن.

## 🔧 عیب‌یابی

### ویجت‌ها نمایش داده نمی‌شوند
- مطمئن شو افزونه Elementor نصب و فعال است
- در نوار جستجوی پنل المنتور `vira` تایپ کن

### استایل به‌هم ریخته نمایش داده می‌شود
- در `Vira Sections → تنظیمات`، **بارگذاری فونت Vazirmatn** را فعال کن
- اگر افزونه کش (LiteSpeed/WP Rocket) داری، Minify CSS و JS را برای این صفحات خاموش کن

### JavaScript کار نمی‌کند
- هر ویجت اسکریپت inline دارد و باید کار کند
- اگر افزونه کش JS Defer دارد، آن را برای این صفحات استثنا کن
