## ⚡ پیاده‌سازی در المنتور (۳ مرحله)

### مرحله ۱: تنظیم صفحه
1. برو به **پیشخوان → برگه‌ها → برگه سئو گوگل**
2. **ویرایش با المنتور**
3. محتوای فعلی را پاک کن
4. تنظیمات صفحه:
   - **Page Layout** → `Elementor Full Width`
   - **Hide Title** → ✅

### مرحله ۲: افزودن ۸ سکشن
برای هر سکشن:
1. ➕ سکشن جدید → یک ستون
2. Content Width → Full Width, Padding → 0
3. ویجت **HTML** درگ کن
4. محتوای فایل سکشن رو کپی-پیست کن
5. تکرار برای ۸ سکشن

### مرحله ۳: Update / انتشار ✅

## ⚠️ نکات مهم

- **JavaScript**: مطمئن شو افزونه کش (LiteSpeed/WP Rocket) JS Minify رو برای این صفحه خاموش کرده
- **فونت**: Vazirmatn از CDN بارگذاری می‌شه. اگر فونت دیگه‌ای داری، در CSS هر سکشن تغییر بده
- **URL**: آدرس `/seo-google/` رو تغییر نده (برای حفظ سئو)
- **H1**: فقط یک H1 در Hero — بقیه H2/H3

---

## ✏️ ویرایش متن

هر متن داخل تگ‌های HTML قابل تغییره. فقط به `<style>`, `<script>`, `class=""` و `<svg>` دست نزن.

### تغییر رنگ:
در ابتدای CSS هر سکشن:
```css
--vs-green:#22c55e;  /* ← رنگ سبز سئو */
--vs-primary:#170C79;
```
