## ⚡ پیاده‌سازی در المنتور

### مرحله ۱: تنظیم صفحه
1. **پیشخوان → برگه‌ها → برگه آموزش سئو در تبریز**
2. **ویرایش با المنتور**
3. محتوای فعلی پاک شود
4. تنظیمات صفحه:
   - **Page Layout** → `Elementor Full Width`
   - **Hide Title** → ✅
   - **Padding** سکشن مادر → 0

### مرحله ۲: افزودن ۸ سکشن
برای هر سکشن:
1. ➕ سکشن جدید → یک ستون
2. Content Width → Full Width, Padding → 0
3. ویجت **HTML** درگ کن
4. محتوای فایل سکشن کپی-پیست شود
5. تکرار برای ۸ سکشن

### مرحله ۳: انتشار ✅
